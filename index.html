    ℹ️ About RainWise & the Formula

    🌍 The Problem

    India receives over 4,000 billion m³ of rainfall annually, yet 600 million people face water stress. Most rain runs off rooftops into stormwater drains — wasted. Rainwater harvesting captures this free resource at source, reducing bills, recharging aquifers, and building resilience.

    🧮 The Formula

    Harvest (L) = max(0, Rainfall − First Flush) mm × Roof Area m² × Runoff Coefficient

    The runoff coefficient (0.80–0.90 for rooftops) accounts for evaporation and surface absorption. The first flush (1–2 mm) diverts the dirty initial rain. Tank simulation: Tank = min(Capacity, Tank + Harvest) − Daily Use ≥ 0. Any excess beyond capacity is tracked as overflow.

    🛠️ Technology

    • HTML + CSS + Vanilla JavaScript — no build step, hosts on GitHub Pages
    • Open-Meteo API — free weather data, no API key needed
    • Chart.js 4 — interactive data visualisation
    • localStorage — persists your inputs between sessions

    📡 Data Sources

    • Open-Meteo Geocoding API — city → lat/lon
    • Open-Meteo Forecast API — past 30 + next 7 days
    • Open-Meteo Archive API — last 365 days
